# Franchisor CSAT templates

The franchisor's owner and resident email and text templates are not copied here. Read the current season's set from the RPM Intranet (RPM Libraries › Operations Library › Office Operations, search "CSAT Template") as SKILL.md step 3 describes, or use the copies attached to the coach's timeline email. If neither is available, ask the user to paste the wording.

## Notes that apply whatever the wording

- Templates have no sign-off: add the franchise name or the user's name and title.
- If there is no resident text template, draft one in the same short style as the owner texts, mark it as not from the franchisor, and get the user's approval.
- If there is no final-reminder template, draft one from the reminder ("The survey closes on [close date]...") and mark it as not from the franchisor.

## Merge fields

Realm-X bulk messages support tenant name, current rent, unit name/address and property name/address. A first-name-only field isn't documented, so check the insert fields in the AppFolio draft window; if none fits, use "Hi there". AppFolio owner letters have an **Owner First Name** field (Insert Field in the letter editor). See `appfolio-owner-letters.md`.
